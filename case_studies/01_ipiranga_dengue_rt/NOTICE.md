data redistributed here**, and records what is and is not known about the redistribution

## 2. Third-party material redistributed here

| Path | What it is | Origin |
|---|---|---|
| `artifacts/data/ds_2023-12-01_2025-12-28/data.parquet` | 109 municipality-weeks of dengue notification counts, Ipiranga (PR), IBGE 4110508 | **InfoDengue**, retrieved via the **Mosqlimate** API on 2026-11-25 |
| `artifacts/data/ds_2024-12-01_2026-01-15/data.parquet` | 59 municipality-weeks, same municipality, overlapping window | InfoDengue via Mosqlimate |
| `artifacts/data/*/ro-crate-metadata.json` | Machine-generated RO-Crate descriptors for the above | generated by the retrieval tool |
| `artifacts/derived/ipiranga_weekly_2025.parquet` | 57-row weekly aggregation derived from the above | derived during the investigation |
| `artifacts/derived/ipiranga_biweekly_2025.parquet` | 29-row biweekly aggregation | derived during the investigation |

The derived files are **derivative works** of the upstream data and inherit its terms;
deriving them does not remove those terms.

### What the archived provenance records about licensing

The RO-Crate files are the only provenance record archived for these datasets. They were
inspected in full during the verification pass. They contain:

- `name`, `description`, `datePublished`, `spatialCoverage`, `wasDerivedFrom: #Mosqlimate`;
- a file entry with `contentSize`, `encodingFormat`, and the column schema;
- `#field_sources` with `spatial_coverage: "data_inferred"`.

They contain **no `license` field, no `creator`, no `publisher`, and no terms-of-use
reference**. The archive therefore carries **no record of the upstream licence**.

### What is known about the upstream terms

- **Not verified for this dataset.** The InfoDengue / Mosqlimate terms of use applicable
  to municipality-level dengue notification counts could not be retrieved and confirmed
  during this session. No licence is asserted here.
- **A related but different dataset does not transfer.** Mosqlimate documentation in the
  knowledge base states that the *Mosqlimate Aedes aegypti Egg Image Dataset* is available
  "for non-commercial research purposes only". That statement concerns an **image**
  dataset, not the dengue case counts used here. It must **not** be read as the licence
  for these Parquets, in either direction.
- **Do not assume open-licensed.** Municipality-week aggregates of notifiable-disease
  counts are distributed publicly by Brazilian health information systems, but public
  availability is not the same as an explicit redistribution licence.

## 3. Personal data

None. Both Parquets are **aggregated municipality-week counts** (columns include
`casos`, `casos_est`, `p_inc100k`, `Rt`, climate covariates). There are no individual
records, no patient identifiers, and no municipality smaller than the municipality
itself. The reproduction and verification scripts introduce no additional data.

## 4. Outstanding action before this is treated as a public data release

Redistribution permission for the two `artifacts/data/**/data.parquet` files is
**UNVERIFIED**. Until it is resolved, one of the following should be done:

1. **Confirm the upstream terms** with InfoDengue/Mosqlimate and record the licence and
   attribution string in this file and in the root `LICENSE`; or
2. **Stop redistributing the Parquets** and replace them with a retrieval script plus the
   `MANIFEST.csv` checksums, so users fetch the data from the source themselves. The
   analysis is fully reproducible this way — the estimator only needs `data_iniSE`, `SE`,
   `casos`, `p_inc100k`; or
3. **Mark this directory as not for redistribution** and keep it private pending
   resolution.

Option 2 is the safest default for a public repository and costs nothing analytically.
